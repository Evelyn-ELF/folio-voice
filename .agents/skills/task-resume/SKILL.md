# 核对现场并继续任务

先读取仓库根目录的[README](../../../README.md)、[AGENTS](../../../AGENTS.md)及[开发任务当前项](../../../docs/开发任务.md#now)。执行[工程规范3.7](../../../docs/工程规范.md#development-interruption)的统一恢复顺序；出现意外情况时只读取相应场景，完整规则以该章节为准。

在修改前核实分支、已有修改、未跟踪文件、未结束命令及结果不明的操作；将恢复结论记入原F任务，再从第一项未完成且依赖满足的步骤继续。复用仍有效的成果与证据，保留原授权和最新用户修正。模型配置按原流程确认，不能用历史记录推断实时设置；不因本技能新增其他审批。此技能只恢复已有目标，不授权重复外部写入、重建空工作区、提交推送或创建自动化。
