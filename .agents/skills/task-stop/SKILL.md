# 整理并结束任务

先读取仓库根目录的[README](../../../README.md)、[AGENTS](../../../AGENTS.md)及[开发任务当前项](../../../docs/开发任务.md#now)。执行[工程规范3.7](../../../docs/工程规范.md#development-interruption)中“用户提前提醒时的正常收尾”，完整规则以该章节为准，不在技能中维护副本。

只做当前任务的有界收尾，把现场核实结果和续做位置保存到原F任务；保留已有修改，按实际结果区分已保存、仍运行、结果待核实与未完成检查。最后简要说明保存结果和下一步，停止推进。此调用不授权提交、推送、清空工作区、退出客户端或关闭电脑，也不替代对未知进程的身份核实。
