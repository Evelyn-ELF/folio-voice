## 1. 验证目标、层级与进入条件

验证必须回答三个问题：产品需求是否满足、关键设计假设是否成立、失败时是否保持内容与数据安全。

| 编号 | 验证对象 | 使用方式 |
|---|---|---|
| V01–V21 | 全部产品需求 | 作为需求覆盖与最终验收索引 |
| E01–E08 | 文本、恢复、声音、同步、PDF、容量、策略与Agent风险 | 决定参数、能力边界及是否继续投入 |
| C01–C12 | 质量裁决、权限、修复和放行契约 | 固化成确定性正反例及竞态测试 |

工程骨架先按工程规范N27–N29/S40–S45运行统一检查。静态边界必须以受控越层和循环负例揭露错误；环境按锁安装，记录依赖及许可元数据；真实回环HTTP检查只证明存活/拒绝/页面资源和路径隔离。容器配置解析、镜像构建及容器启动分别记录；容器与本机共用HTTP断言，核对非root身份和锁定依赖，用只读自写测试输入重跑存储回归，并核实失败/成功路径的临时容器回收。容器Mac入口诊断不代替原生Mac实测。远端CI及必需检查启用须有远端实际证据。没有浏览器交互或安装/模型实测时明确留空，不拿构建或诊断结果代替V10/V16/V18/V19。

先用静态、单元、契约和模拟执行器验证确定性逻辑，再做真实模型、真实标注、API和设备实验；证据分层登记，不相互替代。执行依赖见[开发任务](开发任务.md#sequence)。

每项运行前必须冻结目标、范围、输入、环境、预算、预期及停止条件。真实书籍试验仅第六章，先认可小样再扩章；其他风险和规模样本用自写或合法授权材料。缺少真实评估资源时，可以继续独立开发，但不能激活对应自动交付资格。

## 2. 环境、样本与证据规则

实验用于决定设计是否可行、参数是否合理以及是否值得投入下一阶段。先验证文本保真与恢复，再验证现有声音的可控生成、最终编码同步，最后验证通用PDF和容量。若试验失败，修改对应设计假设，不通过增加重试或降低验收要求绕过失败。

依据S05/S06的公开测试过程和文档范围组织；以下样本数量、阈值与停止条件均是项目实验设计，不是标准规定。按[工程规范的证据格式](工程规范.md#testing)保存环境、输入散列、预期/实际、证据和缺陷。本文件不代替逐文件实施计划，也不表示已开始制作。

- 每次运行记录：代码提交/未提交补丁指纹、OS/设备、依赖锁、模型与参考素材散列、精度、参数、种子、输入范围、操作者和时间；模型可重复性限于记录条件，不承诺相同种子跨环境逐字节相同。
- 同一次比较只改变一个主要因素。文本、声音或基线变化时另建实验，不能把多个变量一起更换后的优胜归因于其中一个。
- 声音评分只由实际听过该文件的人员填写；自动工具不得替填。候选播放顺序随机且隐藏配置标签，评分后再揭示，降低先入为主的影响。
- 成本包含失败与被弃用候选，不只统计最好结果。保留全部尝试及排除理由；报告样本数量和风险类型，零错误样本不外推“全书永不出错”。
- 每个实验具有明确预算和停止条件；到达预算后列待处理问题，不无限搜索随机种子。已有认可声音不因某次自动分数较高而被替换。

## 4. 关键风险实验

实验先冻结预期和失败决策，再执行。每项保留编号，标题描述验证对象；结果只在开发任务关联证据。

<a id="e01"></a>

### 4.1 E01：文本保真与来源覆盖

**假设与设计影响：** 来源清单及映射足以在TTS之前发现新增标点、漏文、乱序和未登记排除；失败则不允许批量推理。

**样本：** 自写短EPUB包含跨span中文、text/tail、引号括号、ruby、上下标、小数/单位、图表及文献紧接正文；配套文字/扫描/混合PDF覆盖跨页段落。另在本地核实第六章来源清单，私人文本不进入公开测试。

**过程：** 建立人工预期来源清单；分别注入词内、短语内及跨节点的错误句号、重复段落、漏节点、顺序交换、正文误判文献、单位规范化错误；运行源→显示→朗读映射及封装反提取检查。确认错误是否在正确阶段被拦截，并保留有意修订的可通过正例。

**通过：** 所有注入差错被相应检查拒绝，合法原文不被擅改；每个正文/排除单元均有出处；比较保留标点。PDF人工真值独立来自原页，不能由同一OCR结果生成预期答案。

**失败决策：** 修正解析/映射后重跑相关样本；不靠后续ASR弥补文本错误。关联R01–R04、INV01/02、V01–V04。

<a id="e02"></a>

### 4.2 E02：持久任务与恢复

**假设与设计影响：** 短事务、不可变制品和租约隔离可处理当前双环境的进程故障；不需要先引入额外消息队列。

**环境：** 最小应用与两个模拟执行器，不加载真实模型；模拟单元有输入/输出散列和可控耗时。首先模拟长于租约周期的任务，验证独立心跳能续租。

**故障点：** 暂存写入中、原子改名后事务前、事务提交后回执前、领取与取消并发、暂停宽限到期、app重启、执行器断线、旧世代提交、修改文本、新快照恢复、磁盘写满、备份与清理并发。每个确定性故障点至少执行一次；关键事务竞态用受控屏障覆盖两种顺序，不用“跑很多次没出错”代替顺序覆盖。

**通过：** 每个逻辑任务最多一个已接受结果；已撤销租约不写新结果；重复请求可取得原回执；父暂停后不启动新单元；取消不复活；完整制品可追溯；新制作不串用错误指纹。清理不删除活跃引用，已完成但回执丢失不再次产生副作用。

重试边界另覆盖：技术尝试有余额的正常重试；额度耗尽后的普通重试被拒；仅追加技术尝试、未追加已耗尽TTS/API预算仍被拒；完整授权后恢复且保留累计消耗。暂停恢复、重建任务和新run均不能隐式清账。

**参数选择：** 先验证120秒/20秒候选组合，在受控测试中缩短时长验证边界，再以真实模型冷加载和高负载验证心跳间隔；租约必须覆盖测得的正常监督抖动及预留余量，失联恢复等待时间同时记录。不能只延长租约掩盖心跳被推理阻塞的问题。

**失败决策：** 若错误来自事务/幂等设计，修正边界；若设备恢复出现双模型进程，先完成本地监督与设备锁，禁止通过增加内存预算掩盖。关联R10/R11/R14、INV05、V10/V11/V14。

<a id="e03"></a>

### 4.3 E03：声音稳定性与配置比较

**假设与设计影响：** 在固定已认可声线与模型基线下，改善输入上下文及边界策略能减少返工；不预设量化是漏字原因。

#### 数据集与预算

从已核验第六章选择12条不同风险语境，覆盖首字、句中、末字、术语语义分组、助词/多音字、数字/单位、长句及相邻段落衔接；同一条可覆盖多类风险。另取一段连续长样。若该章缺某风险，用明确标识的自写材料补充，不冒充原书正文。不生成第五章音频。

预先冻结6条调试样本和6条保留验证样本，不根据候选表现调整分组。首轮比较两个配置、每条两个固定种子，最多48份短样及每配置一份连续长样。先只做调试集，未出现值得保留的改善则停止，不消耗保留集。实际文字范围和预计音频时长形成小样清单，执行遵循既定小样范围与认可门槛。

#### 控制变量与评价

基线记录经小样认可的参考声音、模型及温度等完整配置；未认可时先完成小样，不继承其他制作的认可结论。首轮只比较一种上下文/切点策略；原声与处理音保留对应关系。量化对照在此后作为单独实验，不能同时修改参考、温度、量化、分块和降噪。上游Qwen3-TTS公开接口仅提供能力参考，MLX适配的实际支持须单测。[S19](https://github.com/QwenLM/Qwen3-TTS)

每份音频记录：逐字遗漏/重复/误读、真实发音、语义停顿与重音、声音相似性与稳定性、杂声、切点泄漏；随后记时长、峰值资源、生成时间及是否需重录。ASR和对齐只填自动证据列。对明确音频错误不得用相同汉字识别结果推翻听审。

**选择规则：** 先排除存在已确认未解决缺字、错读、上下文泄漏或声线不可接受退步的候选；剩余候选比较初次合格率、每小时成品机器耗时和复核工作量。只有调试集改善、保留集无已确认退步且连续长样得到认可时，才推荐替换配置。结果接近或证据不足保留原基线，不强行宣布赢家。

**失败决策：** 同一风险在不同种子重复出现时，先定位文本/模型/切点/后处理哪一层首次出错；预算耗尽进入待处理。若新配置无稳定收益，不扩大整章。关联R07/R08、INV03/06、V07/V08。

<a id="e04"></a>

### 4.4 E04：最终编码与阅读器同步

**假设与设计影响：** 章节单轨和句级映射可在最终编码及真机播放中保持内容与跟随正确。

**过程：** 自写样本先覆盖同章多XHTML、非朗读图表/文献、长句多合成块和章末。记录无损母带采样点、编码后解码的有效语音位置及实际偏移；根据测得关系生成时间轴，不能无依据统一减一个常数。再用第六章认可小样核对最终AAC及Readest。

**度量：** 对人工定位的句首/句尾报告偏差分布、最大值、沿章位置趋势和异常点；初始句首目标约200毫秒为项目目标，不是格式标准。测试选择章首/中/末、每个拼接类型及所有风险点；时间单调不代表没有漂移。关键字音不得被clip边界截掉。

**通过：** 文本与资源完整，EPUBCheck及业务检查无未处理失败；最终音轨全量内容筛查通过，开发样本听审符合实验门槛；真机无已确认截字、错句或持续漂移。未支持的阅读器行为明确列限制，不能伪造链接替代实际功能。

**失败决策：** 母带正确、AAC错误则查编码/处理；独立AAC正确、Readest错误则查媒体叠加及播放行为；不可直接以扩大区间修复模型未生成的字。关联R09/R12/R15、INV04/07、V09/V12/V15。

<a id="e05"></a>

### 4.5 E05：PDF提取与来源可信

**假设与设计影响：** 可替换提取/OCR适配器加原页校对能覆盖已确认PDF类型；不要求所有复杂页面自动通过。

使用自写或可再分发页面，至少覆盖文字、扫描、混合、双栏、旋转/倾斜、低清、跨页半词、图表续页及公式。每类有人工独立校对的文本、标点、阅读顺序与区域清单，按页统计差错和纠错时间。OCR A先完成；仅对失败类型或代表性样本引入候选B，不无条件运行所有大模型。

通过条件为校对后应读范围与来源完整、无未处理错误、区域定位正确、恢复不重做已接受区域。自动质量分别报告字符、标点、顺序、遗漏/重复，不用一个平均准确率掩盖整段丢失。不可辨认页面能够阻断并请求更清楚来源。

记录每页自动耗时与人工纠错分钟数，确认复杂类型的人工成本是否可接受；成本过高则调整后端、交互或明确适用限制，不能删除扫描PDF需求。关联R02/R13、V02/V13。

<a id="e06"></a>

### 4.6 E06：容量、局部返工与备份

**假设与设计影响：** 内容指纹能避免不必要重录，单并发方案能在实际机器上稳定运行。

在自写多章材料上完成一轮制作，分别修改一字、参考声音、识别规则和封面；记录哪些制品复用、哪些重建、为何失效。单字修改只重录相关块和依赖上下文的邻块，但全章最终编码变化后重新全量筛查与Q3自动裁决；开发听审按评估实验范围执行；封面修改不触发TTS。任何误复用直接失败。

分别测冷/热启动、逐阶段墙钟时间、总机器时间、内存峰值、换页、Docker卷和宿主暂存空间峰值；以当前真实硬件为准。初始单推理并发，未经测量不启用双模型。长任务观察至少包含模型加载、连续合成、ASR/对齐切换、编码和一次恢复；持续多久及生成量在运行清单中如实记录，不把短测称为长期稳定。

按实测预留磁盘再注入低空间，检查任务停写、恢复和清理边界；生成一致性备份后在独立数据目录恢复，验证源件、声音、修订、所有采用制品和审查记录。若存储增长超出预算，优先减少未采用候选保留量，必须经过清理预览和明确执行，不删除唯一证据或认可声音。

关联R06/R10/R11/R17/R18、V06/V10/V11/V17/V18。

<a id="e07"></a>

### 4.7 E07：自动交付策略资格

责任：开发维护者组织真实标注、工具执行及评估；用户仅确认风格和自愿小样反馈，不承担完整数据集标注。若没有真实听审资源，就明确缺少该项证据，不让LLM生成“人工真值”。

实验数据采用合法可再分发/自写材料和已合法授权的音频缺陷样本；真实书仅第六章已批准小样，其他整章连续样本使用自写材料。调试集和盲测集按来源/文本/缺陷家族隔离；同一句不同种子不能分别进入两边。盲测后调阈值必须换新保留集再测。

首版项目资格门槛（工程目标，未经实测，不是行业标准或统计保证）：

| 维度 | 数据/指标/通过条件 |
|---|---|
| 关键缺陷挑战集 | 至少60个盲测缺陷片段，覆盖首中尾漏字、重复、否定/数值单位错误、裁切、错位及ASR补字；所有关键缺陷均被拦截，不允许以平均分掩盖漏放 |
| 正常输入与误报 | 至少100个无缺陷盲测片段；误判需修复/人工处理比例≤5%，自动修复不得引入新内容错误 |
| 端到端残余错误 | 至少300个自然生成盲测片段，覆盖至少3种已定义文本类型；对实际自动放行部分逐字/逐音人工核验，关键错误为0；同时报告拒绝数量，不只展示成功片段 |
| 连续音轨 | 至少3个不同自写章节，每章≥20分钟，开发评估全量听审最终AAC；检查漂移、章节边界及累积同步，关键错误为0 |
| 用户负担 | 上述连续任务均不要求全章听审/逐书真机操作；每小时音频转给用户的疑点片段总长≤2分钟且去重请求≤3次，无疑点时零确认即可交付 |
| 自动完成率 | 自然生成评估集按预先冻结制作单元统计无需用户处理的完成率≥95%；与错误/阻断率同时报告，不能靠全拒绝通过安全指标 |
| PDF资格 | 文字、扫描、混合分别评估，另冻结人工原页真值；每种待启用类型至少30页且含至少3种版面，漏段/错序/否定数值错误为0；未达类型保持待处理，不宣称自动支持 |

真值由实际听审者/校对者独立于生成及诊断模型制作；争议、全部关键缺陷和至少20%的随机样本由另一名真实人员复核，无法达成结论的样本保留不确定标签并报告，不静默剔除。不在没有标注资源的情况下宣称E07已完成。

上述数量是首轮工程准入门槛，不足以证明任意书籍零错误。报告必须列分母、风险类别、书籍/声音分组、相关样本和不确定性；同章片段相关，不能用独立伯努利假设直接给出整书可靠率。自动完成率分母包含全部预注册任务，不能排除失败、超预算或转人工任务；重试不增加分母。用户负担同时记录最大值和分布，不仅报告均值。任何对外错误率承诺需另设计有代表性的抽样和置信分析。小样通过只允许其策略适用范围，不能自动覆盖其他声音、语言、模型及PDF类型。

资格激活、暂停与变更失效按[系统设计](系统设计.md#quality-gates)执行；实验报告提供相应资格版本与适用范围证据。

开发阶段采用“影子评估”：系统给出拟放行决定，真实评估者在后台标注对照；这不是消费者每次听书流程。上线维护的抽查须有资源与素材许可，不能偷偷上传用户全书或自动把用户播放记录当真值。

<a id="e08"></a>

### 4.8 E08：Agent权限、恢复与收益

自写夹具覆盖：书页提示注入、伪造通过字段、跨书资源访问、模型拒绝/非法结构、401/429/超时、工具已成功但响应丢失、取消/旧世代、预算并发、相同建议循环、资格撤销与release的两种顺序、云端断开、未知阅读器版本。每项要求拒绝/暂停/恢复与预期一致，零越权副作用、零重复重录；计费未知不当零费用，API错误不当质量通过。

逐一验证AgentDecision停止原因映射到正确AgentRun状态；终止状态不能直接续跑，等待状态恢复需重新核验授权与预算。新运行继承同疑点/音频块的累计消耗。

开发依赖及A1–A5步骤见[开发任务](开发任务.md#agent-sequence)。本实验分别记录固定流程、ReAct及ReAct＋反思的质量、成本和误改；无收益时保留建议模式，不扩大自动修改权限。

实施完成条件不是“API能返回JSON”。必须同时具备确定性拒绝测试、真实声学/文本基准、API失败恢复、授权/费用验证和消费者零全量验收的端到端体验。

### 5.2 必需回归类别

回归素材使用自写或合法授权内容，覆盖：跨DOM标签不得插入句号；注入“蛋白。／质”“合成。／蛋白质”“作为。／能量”“这是。／一个”“都。／是”“影响，。”等错误标点；“蛋白质”等词内错误分段；“肌糖原”等术语语义边界；“具体地说”的助词轻声；首中尾漏字与ASR补字；数字、单位、否定词；图表续页与参考文献误混。真实缺陷与自动疑点分开，不能以转写文字相同证明声音正确。具体素材身份、许可和散列由开发任务F01登记。
